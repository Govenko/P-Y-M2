# Yandex Maps Parser — Обходной парсер с двухэтапной стратегией

## 📋 Описание

Надежный парсер Яндекс.Карт для сбора данных об организациях по выбранному городу. 
Использует **двухэтапную стратегию** для обхода лимита в ~500 результатов на запрос.

## 🏗 Архитектура и стратегия обхода лимитов

### Проблема
Яндекс.Карты ограничивают выдачу примерно 500 организациями на один поисковый запрос, 
что недостаточно для полного сбора данных по городу.

### Решение: Двухэтапный подход

#### ЭТАП 1 — Сбор рубрикатора города
1. Переходим на Яндекс.Карты по выбранному городу
2. Открываем фильтр/рубрикатор и извлекаем ВСЕ доступные рубрики
3. Сохраняем список рубрик (обычно 50-500+ категорий)

#### ЭТАП 2 — Поиск по каждой рубрике отдельно
1. Итеративно выполняем поиск по КАЖДОЙ найденной рубрике
2. Каждый запрос возвращает до 500 результатов
3. **Результат**: 100 рубрик × 500 org = до 50,000 организаций вместо 500!

### Преимущества подхода
- ✅ Не требует платных прокси
- ✅ Не требует внешних API капчи
- ✅ Использует `playwright-stealth` для маскировки под человека
- ✅ Человеческие задержки (random 2-6 сек между действиями)
- ✅ Ручное вмешательство при капче (браузер остаётся открытым)
- ✅ Построчное сохранение в CSV — данные не теряются при обрыве
- ✅ Пропуск уже собранных организаций по URL

## 📦 Установка

### 1. Установите зависимости
```bash
pip install -r requirements.txt
```

### 2. Установите браузеры Playwright
```bash
playwright install chromium
```

### 3. Настройте конфигурацию
Скопируйте `.env.example` в `.env` и отредактируйте параметры:
```bash
cp .env.example .env
```

Параметры в `.env`:
- `CITY` — город для парсинга (Москва, Санкт-Петербург, Казань и т.д.)
- `MAX_ORGANIZATIONS` — максимум организаций (0 = без ограничений)
- `OUTPUT_CSV` — путь к выходному файлу
- `DEBUG_MODE` — True показывает браузер, False скрывает
- `MIN_DELAY`, `MAX_DELAY` — задержки между действиями (сек)

## 🚀 Запуск

```bash
python yandex_maps_parser.py
```

## ⚠️ Обработка капчи

Если появляется капча:
1. **Браузер остаётся открытым** (в режиме DEBUG_MODE=True)
2. Парсер выводит предупреждение и ждёт
3. **Решите капчу вручную** в окне браузера
4. Парсер автоматически продолжит работу после решения

Таймаут ожидания капчи — 5 минут (настраивается в коде).

## 🔧 Технические детали

### Используемые технологии
- **Python 3.10+**
- **Playwright (async)** — автоматизация браузера
- **playwright-stealth** — обход базовых детекторов ботов
- **loguru** — красивое логирование
- **csv.DictWriter** — сохранение данных

### Логирование
- Консольный вывод с цветами и временем
- Файл `parser.log` с ротацией (10 MB, хранение 7 дней)
- Логируются: начало парсинга рубрики, успешное сохранение, ошибки полей, ожидание капчи

### Обработка ошибок
- Ошибка парсинга одной карточки НЕ останавливает весь скрипт
- Данные сохраняются построчно сразу после успешного парсинга
- При перезапуске проверяется наличие организации в CSV по URL/названию

## 💡 Советы по использованию

1. **Запускайте в режиме DEBUG_MODE=True** для первого запуска — сможете видеть что происходит
2. **Начинайте с небольшого города** для тестирования
3. **Увеличьте задержки** если видите частые капчи (MIN_DELAY=4, MAX_DELAY=8)
4. **Не закрывайте браузер вручную** — парсер сам закроет его после завершения
5. **Проверяйте CSV файл** во время работы — данные сохраняются построчно
