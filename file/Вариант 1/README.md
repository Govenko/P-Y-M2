# Парсер Яндекс.Карт

Десктоп-приложение для Windows: находит организации **без сайтов** в любом городе России по выбранной сфере деятельности. Подходит для лидогенерации, B2B-обзвонов, продаж сайтов и услуг.

## Возможности

- Выбор сферы (кафе, барбершопы, стоматологии, автосервисы и т.д.) — 35+ категорий
- Выбор города — 50+ городов России
- Фильтр «только без сайта»
- Сбор: название, адрес, телефон, сфера, город
- Экспорт результатов в Excel (.xlsx) с красивым оформлением
- Современный тёмный интерфейс

## Скачать

**[→ Скачать ParserYandex.exe](../../releases/latest)**

Просто запусти `.exe` — никакой установки, никакого Python, всё внутри.

## Как пользоваться

1. Выбери **сферу деятельности** в левой панели
2. Выбери **город**
3. Укажи **максимум результатов** (по умолчанию 60)
4. Нажми **«Запустить поиск»**
5. После завершения — **«Экспорт в Excel»**

## Запуск из исходников

Если хочешь запустить из кода:

```bash
pip install -r requirements.txt
python -m playwright install chromium
python main.py
```

Или просто двойной клик по `install.bat`, затем `run.bat`.

## Сборка `.exe` самостоятельно

```bash
build.bat
```

Файл появится в `dist/ParserYandex.exe`.

## Технологии

- Python 3.10+
- Playwright (управление браузером)
- CustomTkinter (интерфейс)
- openpyxl (экспорт в Excel)
- PyInstaller (сборка `.exe`)
